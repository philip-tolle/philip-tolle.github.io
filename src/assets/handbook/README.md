# Residenzhof-Demomotiv

`residenzhof-demo.webp` ist das vorhandene Hausporträt aus `residenzhof-handbuch-source/public/images/hotel-residenzhof-hausportraet.webp` im gemeinsamen Projekt.

Es zeigt das fiktive Hotel der Betriebshandbuch-Demo. Es ist kein Bildschirmfoto und keine Kundenreferenz. Die Startseite nutzt es als verlinkten Einstieg zur echten, weiterhin geschützten IONOS-Anwendung `https://handbuch.next-course.de/`.
